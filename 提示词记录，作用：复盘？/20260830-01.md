# 新书信息分析框架 v0.1

> 目标：对一本**新出版图书**进行快速、多维、可复用的信息分析，形成类似「图书情报卡 + 市场判断 + 学习价值评估」的结构。框架参考信息分析中的“信息采集—整理—评价—推断”流程。([科学阅读][1])

---

# 0. 基础信息层（Book Identity）

## 0.1 基本元数据

| 项目   | 内容      |
| ---- | ------- |
| 书名   |         |
| 副标题  |         |
| 作者   |         |
| 译者   |         |
| 出版社  |         |
| 出版日期 |         |
| ISBN |         |
| 页数   |         |
| 定价   |         |
| 分类   |         |
| 版本   | 第几版/修订版 |

**分析问题：**

* 这是一本新书，还是经典书再版？
* 出版时间是否对应某个社会趋势？
* 出版社是否具有该领域影响力？

# 1. 主题定位层（Positioning）

## 1.1 一句话定位

模板：

> 这是一本面向【目标人群】，解决【核心问题】，采用【主要方法】，讨论【核心主题】的书。

例如：

> 一本面向高中生的认知科学入门书，通过心理学实验解释学习方法。

---

```
领域：

关键词：
├── 高频概念
├── 核心术语
├── 方法论
└── 应用场景
```

# 4. 知识价值分析层（Knowledge Value）

## 4.1 核心知识类型

判断：

### A. 信息型

回答：

> 世界是什么？

例如：

* 历史
* 科普
* 行业报告

### B. 方法型

回答：

> 如何行动？

例如：

* 管理方法
* 学习方法
* 编程

### C. 思维型

回答：

> 如何理解？

例如：

* 哲学
* 认知科学

### D. 工具型

回答：

> 如何解决问题？

例如：

* 软件
* 技术指南

# 5. 市场信号分析层（Market Signal）

## 5.1 出版信号

观察：

* 是否重点推荐
* 是否系列作品
* 是否名家背书
* 是否多平台推广

---

## 5.2 社会需求匹配

分析：

```
社会趋势
    ↓
用户痛点
    ↓
图书主题
    ↓
购买动力
```

例如：

AI浪潮

↓

大众需要理解AI

↓

AI科普书增加

↓

市场需求增强

# 8. 批判性分析层（Critical Review）

## 8.1 优点

检查：

* 是否有原创观点？
* 是否系统？
* 是否案例丰富？
* 是否容易实践？

---

## 8.2 局限

检查：

* 是否过度理论化？
* 是否依赖旧资料？
* 是否缺少案例？
* 是否存在作者偏见？

# 10. 综合评分模型 v0.1

100分：

| 项目    | 权重 |
| ----- | -: |
| 主题价值  | 20 |
| 作者可信度 | 15 |
| 内容结构  | 20 |
| 方法贡献  | 15 |
| 实践价值  | 15 |
| 市场意义  | 10 |
| 可读性   |  5 |

公式：

```
Book Value Score
=
Σ(指标 × 权重)
```

## v0.2 可升级方向

下一版可以加入：

1. **LLM辅助新书分析流程**

   * ISBN → 自动抓取元数据
   * 目录 → 知识图谱
   * 评论 → 情感分析

2. **知识资产评估模型**

   * 可迁移知识
   * 可复用方法
   * 可形成技能

3. **个人学习决策模型**

   * 值不值得读
   * 先读还是后读
   * 是否购买纸书

这会更接近“个人知识管理系统”的图书分析框架。
