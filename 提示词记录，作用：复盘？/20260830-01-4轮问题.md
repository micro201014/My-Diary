# 3

下面继续扩展为**「微观规训 / Objectification / Sexualization」人物设计分析问答题版**。

理论基础主要来自：

* **Objectification Theory（客体化理论）**：关注个体如何被观看、评价，并可能内化“作为被观看对象”的视角。([数字对象标识符][1])
* **Male Gaze（男性凝视）**：分析视觉媒介如何通过镜头、构图、叙事安排制造观看位置。([数字对象标识符][2])
* **Sexualization（性化）研究**：关注角色价值是否被压缩为外貌、身体吸引力等维度。([PubMed][3])
