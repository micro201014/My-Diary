下面给出一套**用于 AI 分析 GB/T 标准文件的扩展提示词（Prompt Framework）**。目标不是简单总结标准，而是进行**结构化解读、知识抽取、应用迁移、批判分析、标准体系定位**。

GB/T 标准文件通常具有较强结构化特征，例如范围、规范性引用文件、术语定义、技术要求、试验方法、附录等要素；GB/T 1.1-2020 也规定了标准化文件的结构、起草规则和要素表达方式，可作为分析标准文本结构的参考框架。([全国标准信息公共服务平台][1])

# GB/T 标准文件深度分析 Prompt v1.0

## 1. 基础信息提取

```
请分析以下 GB/T 标准文件：

【标准编号】
【标准名称】
【发布日期】
【实施日期】
【替代关系】

请提取：

1. 标准基本信息
2. 发布机构
3. 适用范围
4. 标准对象
5. 标准目标
6. 标准解决的问题
7. 标准所属领域
8. 标准类型：
   - 基础标准
   - 技术标准
   - 管理标准
   - 方法标准
   - 产品标准
   - 服务标准

输出表格。
```

# 2. 标准结构解析 Prompt

```
请按照 GB/T 标准文件结构分析该标准。

分析：

## 一、文件结构

1. 前言
   - 制定背景
   - 修订原因
   - 与其他标准关系

2. 范围
   - 标准覆盖对象
   - 不覆盖对象
   - 使用边界

3. 规范性引用文件
   - 依赖哪些标准
   - 标准之间关系

4. 术语和定义
   - 核心概念
   - 关键术语关系
   - 概念体系

5. 技术内容主体
   - 核心章节
   - 逻辑关系
   - 强制要求

6. 附录
   - 规范性附录作用
   - 资料性附录作用


输出：
标准结构树。
```

## 推荐组合使用顺序

如果目标是**学习/研究一个 GB/T 标准**：

```
① 基础信息提取
        ↓
② 结构解析
        ↓
③ 核心逻辑提取
        ↓
④ 规则拆解
        ↓
⑤ 行业分析
        ↓
⑥ 批判分析
        ↓
⑦ 教材化转换
```

如果目标是**利用 AI 快速读标准文件**，最有效的是：

> 「结构解析 + 规则拆解 + 知识图谱 + 行业影响分析」

这一组合可以把一个几十页标准转换为可学习、可比较、可迁移的知识体系。
