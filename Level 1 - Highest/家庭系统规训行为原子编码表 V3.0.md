# 家庭系统规训行为原子编码表 V3.0

## 250个原子行为码：操作性定义＋正例＋反例＋边界条件＋强度锚点

### 一、统一编码规则

**编码单位：** 一个可以独立回答“发生/未发生”的具体动作。

**不要编码：**

* “父母很严格”
* “家庭氛围压抑”
* “妈妈控制欲很强”
* “他觉得自己没有自由”

这些是**解释/结果/总体评价**，不是原子行为。

**应该编码：**

* “每天要求孩子报告几点回家”
* “孩子不同意时，父亲说‘你这么想让我很失望’”
* “未经允许查看孩子手机”
* “因为没有听话而扣除零花钱”

---

## 强度锚点统一标准

| 分数 | 强度                       |
| -- | ------------------------ |
| 0  | 未发生 / 纯粹描述，不构成控制         |
| 1  | 低强度、一次性、可协商、影响范围小        |
| 2  | 明确要求或反复出现，开始限制选择         |
| 3  | 高频/侵入性明显，伴随惩罚、羞耻、威胁或资源压力 |
| 4  | 系统性、持续性、多领域，明显剥夺自主性或形成强制 |

**注意：**“强度”不是“道德评分”。例如“规定晚上10点睡觉”可能是 1；如果是“成年人必须10点睡，否则扣生活费”，则可能是 3。研究上应该根据**行为＋语境＋后果**共同评分。

# AC. 强度评分的最终锚点

### I1：低强度结构

满足大部分：

* 一次/低频
* 有明确合理目的
* 可以讨论
* 可以拒绝或修改
* 无羞辱
* 无威胁
* 无重要资源后果

例：

> “今晚早点回来，明天还要上课。”

---

### I2：明确行为控制

通常包含：

* 明确规定
* 持续执行
* 有轻微后果
* 对某一生活领域形成限制

例：

> “晚上10点前必须回家，超过时间这个周末不能出去。”

---

### I3：高侵入控制

通常出现：

* 高频监督
* 私人领域介入
* 多种惩罚
* 羞耻/内疚
* 经济或社交压力
* 明显降低选择空间

例：

> “你每天都必须报告在哪里、跟谁在一起，还要开定位；不照做就扣生活费。”

---

### I4：系统性强制/支配

通常满足：

* 多领域同时控制
* 长期持续
* 明显威胁
* 经济/住房/关系等关键资源被用作服从工具
* 隔离外部支持
* 强制限制行动
* 身体强制或严重威胁

例：

> “不按照家里的安排工作、恋爱、居住，就不给钱、不让你住家里，而且不许告诉别人。”

**I4不是“严格教育”的同义词，而是表示已经出现明显的系统性自主权剥夺。**

# AE. 一个完整编码示例

### 原始材料

> “我大学毕业以后想去上海工作，我妈说不行，家里已经给我找好了本地的工作。如果我非要去，她就说以后房子和钱都不会给我。后来我只好留下来了。”

### 原子编码

| 片段            | 行为码       | 机制      | 强度 |
| ------------- | --------- | ------- | -: |
| “不行”          | AUT03     | M01     |  2 |
| “家里已经找好了本地工作” | E16       | M14     |  2 |
| “不允许去上海工作”    | AUT03     | M01/M10 |  3 |
| “以后房子和钱都不给你”  | M13/ECO12 | M10/M19 |  4 |
| “只好留下来了”      | OUT01     | —       |  — |

### 系统层面

最终可以得到：

**职业控制 + 居住控制 + 经济控制 → 威胁 → 自主选择被放弃**

这比简单写：

> “母亲控制女儿职业。”

具有更高的分析分辨率。

# AF. 最后一个重要规则：不要把“控制”与“坏”直接等号

这个 codebook 最适合做**描述性编码**。

建议最终分析时至少保留四个独立变量：

**Behavioral Control（行为控制）**

×
**Psychological Control（心理控制）**

×
**Autonomy Support（自主支持）**

×
**Coercion/Intrusion（强制/侵入）**

因为研究显示，**高监测＋高自主支持**与**高监测＋高心理控制**是完全不同的家庭模式；前者并不能简单地归类为“控制型家庭”。

因此，一个家庭可能同时是：

> **高规则 + 高监督 + 高自主支持**

也可能是：

> **高规则 + 高监督 + 高心理控制 + 低自主支持**

两者在编码上必须能够被区分。

## V3.0 的核心逻辑

最终不是得到一个简单的：

> **“这个家庭规训程度 = 78分。”**

而应该得到一个家庭的**规训结构画像**：

**时间控制**
＋ **空间控制**
＋ **身体控制**
＋ **学习控制**
＋ **经济控制**
＋ **社交控制**
＋ **信息监控**
＋ **心理控制**
＋ **关系隔离**
＋ **家庭等级**
＋ **自主支持**

再进一步观察：

> **哪些控制行为彼此共现？**

例如：

**经济依赖 → 住房依赖 → 职业控制 → 婚姻控制**

或者：

**监视 → 发现偏离 → 羞耻 → 惩罚 → 成员内化**

这时候，“家庭规训”才真正成为一个可以进行**扎根理论、主题分析、案例比较、频次统计、共现网络分析以及家庭权力结构分析**的研究变量。
